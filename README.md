# TI-Resources

Acest repository conține notițele, materialele și exercițiile mele din facultate, mai exact de la TI.  
Scopul este să centralizez resursele utile pentru învățare și recapitulare, atât pentru mine, cât și pentru oricine vrea să aprofundeze aceleași cursuri.

## Conținut
- 📘 **Notițe** – rezumate teoretice, explicații și concepte importante din cursuri.  
- 💻 **Exerciții** – probleme rezolvate și exemple practice din laboratoare sau proiecte.  
- 🧠 **Resurse** – linkuri, articole și documente suplimentare care pot ajuta la înțelegerea materialului.

## Structură
Fiecare director va corespunde unei materii sau unui semestru, pentru a menține totul organizat și ușor de navigat.

## Observații
Repository-ul este în continuă actualizare, pe măsură ce adaug noi materiale sau îmbunătățesc notițele existente.
